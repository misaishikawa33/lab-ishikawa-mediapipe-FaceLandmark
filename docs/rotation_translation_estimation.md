# 回転行列Rと並進ベクトルtの求め方

本研究では、顔モデルの位置姿勢を推定するために、回転行列 `R` と並進ベクトル `t` を求めている。

回転行列 `R` は、顔モデルがカメラに対してどの向きを向いているかを表す。並進ベクトル `t` は、顔モデルがカメラに対してどの位置にあるかを表す。

これらは、3D点と2D点の対応関係から求める。実装では、OpenCVの `cv2.solvePnP()` を使用している。

## 使用する点

まず、基準となる3D点を用意する。

```text
テクスチャー画像 face1.jpg
↓
MediaPipe FaceMeshでランドマークを検出
↓
各ランドマークを3D座標として保存
```

例えば、ランドマーク33番と263番は以下のような3D点として扱われる。

```text
ランドマーク33番  →  3D点 P33 = (X, Y, Z)
ランドマーク263番 →  3D点 P263 = (X, Y, Z)
```

次に、評価対象画像から2D点を取得する。

```text
評価対象画像
↓
MediaPipe FaceMeshでランドマークを検出
↓
画像上の2D座標を取得
```

例えば、同じランドマーク33番と263番は以下のような2D点として扱われる。

```text
ランドマーク33番  →  2D点 p33 = (u, v)
ランドマーク263番 →  2D点 p263 = (u, v)
```

このとき、同じランドマーク番号同士を対応させる。

```text
3D点 P33   ↔   2D点 p33
3D点 P263  ↔   2D点 p263
```

## PnPによる位置姿勢推定

3D点と2D点の対応を `cv2.solvePnP()` に入力する。

```python
success, rvec, tvec = cv2.solvePnP(
    point_3D,
    point_2D,
    camera_matrix,
    dist_coeff
)
```

ここで、`point_3D` は3Dランドマーク座標、`point_2D` は画像上の2Dランドマーク座標である。

`camera_matrix` はカメラ内部パラメータ行列であり、焦点距離と画像中心から作成する。

```text
K =
[ f   0   cx ]
[ 0   f   cy ]
[ 0   0    1 ]
```

ここで、`f` は焦点距離、`cx` と `cy` は画像中心座標である。

`solvePnP()` の出力は以下である。

```text
rvec:
回転ベクトル

tvec:
並進ベクトル
```

`rvec` は回転行列そのものではないため、Rodrigues変換を用いて回転行列 `R` に変換する。

```python
R = cv2.Rodrigues(rvec)[0]
```

`tvec` は並進ベクトル `t` として使用する。

```text
R = 顔モデルの向き
t = 顔モデルの位置
```

## 投影式

3D点 `P = (X, Y, Z)` は、まず回転行列 `R` と並進ベクトル `t` によってカメラ座標へ変換される。

```text
P_camera = R P + t
```

成分で書くと以下である。

```text
[ Xc ]   [       ] [ X ]   [ tx ]
[ Yc ] = [   R   ] [ Y ] + [ ty ]
[ Zc ]   [       ] [ Z ]   [ tz ]
```

次に、カメラ座標上の点を画像座標へ投影する。

```text
u = f * Xc / Zc + cx
v = f * Yc / Zc + cy
```

ここで、`(u, v)` は画像上の座標、`f` は焦点距離、`(cx, cy)` は画像中心である。

PnPは、投影された点 `(u, v)` が、MediaPipeで検出された2Dランドマーク点にできるだけ近くなるように、`R` と `t` を求める。

つまり、以下を満たすような位置姿勢を推定している。

```text
3Dモデルをどの向きR、どの位置tに置けば、
画像上のランドマークに最もよく重なるか
```

数式では以下の投影関係を用いる。

```text
s [u, v, 1]^T = K [R | t] [X, Y, Z, 1]^T
```

ここで、`s` はスケール係数、`K` はカメラ内部パラメータ行列である。

実際には、すべての対応点について投影誤差が小さくなるように、以下の最小化問題を解いている。

```text
min Σ || p_i - project(K, R, t, P_i) ||^2
```

ここで、`P_i` はi番目の3Dランドマーク、`p_i` はi番目の2Dランドマークである。

## 評価での使用

評価では、求めた `R` と `t` をCSVに保存する。そして、マスクなし画像の姿勢推定結果を基準として、マスクあり画像の姿勢推定結果との差を計算する。

回転の差は、回転行列 `R` のノルム差として求める。

```text
||R_target - R_base||_F
```

並進の差は、並進ベクトル `t` のユークリッドノルム差として求める。

```text
||t_target - t_base||_2
```

これにより、YOLO補正を使用した場合と使用しない場合で、マスクなし画像の姿勢推定結果にどれだけ近いかを比較している。
